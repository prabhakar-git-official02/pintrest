# Pinterest Clone Backend

## Overview

A scalable backend API for a Pinterest-style social media application built with Node.js, Express.js, and MongoDB. The application provides secure authentication, user profile management, image upload functionality, and post management through RESTful APIs.

## Backend Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* Multer
* Bcrypt
* Crypto

## Features

### Authentication

* User Registration
* User Login
* Logout Functionality
* Access Token & Refresh Token Management
* Forgot Password
* Reset Password
* Current User Profile (Me Endpoint)

### User Management

* Create User Profile
* View User Profile
* Update User Profile
* Delete User Profile

### Post Management

* Create Posts
* View Posts
* Update Posts
* Delete Posts
* Dynamic Route Handling

### Image Upload

* Image Upload using Multer
* Server-Side File Storage Handling

## Architecture

* MVC Architecture
* RESTful API Design
* Mongoose Database Integration
* JWT-Based Authentication & Authorization
* Protected Routes using Authentication Middleware
* Dynamic API Routing

## Models

* User Model
* Profile Model
* Post Model

## Security Features

* Password Hashing with Bcrypt
* JWT Authentication
* Refresh Token Handling
* Protected API Routes
* Secure Password Reset Workflow
